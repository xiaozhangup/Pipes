# Pipes 管道模型：旋转去重与输入／输出全状态

第四版保留 200 个模型 JSON：四种可见材质各 1 个普通管道、47 个转角基础模型，另有 8 个物品模型。涂蜡铜复用铜。

打开 `pipes-all-states.bbmodel`，默认显示铜材质的 48 个基础模型，按 8 列排列。其余材质在独立分组中，查看时隐藏铜分组并显示对应分组。模型没有再按东南西北和上下方向重复铺开。

## 上一版漏掉了什么

上一版只枚举主输出与附加输出，还把主方向背面固定画成“安装／输入端”。这不能表达真正的输入组合：例如北面输出、东面输入本应是 L 形，上一版却额外带着南侧的固定短管。

本版去掉这个固定输入假设。转角由中心接头、实际输入面、实际输出面组成；未连接的方向只显示接头侧面。保留输入端无外层箍带、输出端有箍带的区别。原始头颅载体的占位与输入端分开处理，不再据此强行增加一个流路分支。

## 代码核对与覆盖边界

- `PipeListener.onBlockPlace`：普通、转角管道都使用 clickedFace，支持六向。枚举中旧的“转角反向放置／不能朝上”注释不符合执行代码。
- `PipeManager.getCornerActiveOutputFaces`（512 行）：主输出始终存在；其他面在邻接可接收容器或朝向相同的普通管道时成为附加输出。不会仅因为旁边是转角管道就自动增加侧向输出。
- `canRouteIntoAdjacentPipe`（542 行）、`findDestination`（1558 行）：进入转角时，来流面不能等于该转角的主输出面，其余五面均可进入；不是只允许主方向背面进入。
- `tryCornerJunctionAlternatives`（1269 行附近）：按当前路径确定入流面，分流时排除入流面和已尝试的主输出面。多个方向可以邻接朝向本转角的上游管道，它们在不同路径上分别输入。
- `config.yml`：铜、铁、金、氧化铜、涂蜡铜五种逻辑材质，各有普通／转角两个变体。氧化和涂蜡用材质别名覆盖；空闲、输送、休眠和阻塞没有单独纹理。

每个转角固定一个主输出，其余五面分别枚举“无连接／输入／附加输出”，共 `6 × 3⁵ = 1458` 个带主方向的状态。输入和输出互斥，主输出不允许作为输入。每种组合都可通过在对应面放置朝内或朝外的普通管道构造；零输入保留为未接入上游的放置状态，零输出不属于代码状态。

同一个外形可以有不同主输出优先级，这个差别留在状态映射里，不复制几何。去掉主输出标记后，每材质有 665 个有方向的输入／输出组合；按 24 种正交旋转归并为 47 种基础转角。

| 转角轮廓 | 区分输入／输出后的基础模型数 |
| --- | ---: |
| 单口，未接入上游 | 1 |
| 直通 | 2 |
| L 形 | 2 |
| 平面 T 形 | 5 |
| 三轴三通 | 3 |
| 平面十字 | 5 |
| 立体四通 | 9 |
| 五通 | 11 |
| 六通 | 9 |
| 合计 | 47 |

仅看端口占用位置是 9 种轮廓；输入／输出外观不同，因此 47 种不能再全部合并成 9 个模型。只使用旋转，不把镜像当作旋转。

**接入边界：** 现有 `getCornerActiveOutputFaces` 只生成输出展示实体。本资产集合按输送逻辑补齐输入端，尚未修改插件来扫描输入面或选择这些新模型。接入时需要从邻居管道的朝向识别输入面，并使用这里的映射；本次没有部署服务器，也未作游戏内验收。原有实际头颅载体和实体坐标补偿不能直接与本模型重复叠加。

## 旋转与状态映射

`states.json` 包含：

- `models`：192 个放置基础模型、各自输入／输出面、工程分组 UUID 与展示偏移。
- `cornerFamilies`：47 种基础转角定义。
- `states`：四种外观的 5856 条映射，记录材质、行为、主输出、输入面、输出面、模型文件和旋转 ID。
- `rotations`：24 个旋转矩阵、面映射及 `(x,y,z,w)` 四元数。
- `aliases`：涂蜡铜到铜的映射。算入涂蜡后共有 7320 个逻辑放置状态，另有 10 个逻辑物品状态。

局部坐标 `+X=东、+Y=上、+Z=南`，旋转中心为 `(8,8,8)`：

```text
targetPoint = (8,8,8) + matrix × (basePoint - (8,8,8))
```

`faceMap[i]` 给出基础模型第 i 个方向旋转后的方向下标；方向顺序为 north、south、east、west、up、down。主输出优先级使用状态的 `primary`，不要从基础模型的名字推断。`canonicalPrimary` 表示该主输出在基础模型坐标中的方向。

该旋转集合描述模型到世界的方向变换，不能简单把任意旋转 ID 当作原版 blockstate 的单组 x/y 参数。ItemDisplay 渲染器另有本地 Y 轴 180° 旋转，插件在展示变换的右旋转中用 `(0,1,0,0)` 抵消，左旋转使用这里的四元数。纹理与整个模型一起旋转，不使用 uvlock 固定世界朝向。

## 贴图与几何

- 复用原始头颅贴图和上一轮修正的四张模型图集，未重新调色或插值放大。
- 采用统一的北向管段作为基础件，通过旋转生成其他端口，竖向不再另外导出同一基础模型的旋转副本。
- 长管沿轴向每模型单位对应一纹素；短管从箍带端截取实际长度，保留已经修正的顶面箍带方向。
- 管身截面 8×8，中心接头为 8.8³；输出外层横向增厚 0.25，管口底面后退 1/64 避免共面闪烁。
- 所有端口最外缘贴齐 `[0,16]³` 边界；不按空气、箱子、漏斗等连接类型拉伸。
- 管口仍使用原贴图深色面表现，不新增贯穿内腔。
